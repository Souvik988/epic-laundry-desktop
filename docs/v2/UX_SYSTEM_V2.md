# Epic Laundry V2 — UX System

## Current strengths

The app has role-aware navigation, clear operational pages, local branding and a
visible overview. Existing screens use a consistent visual language but rely on
repeated page-specific colors and a flat sidebar.

## V2 direction

- Define semantic design tokens and reusable feedback, table, form and dialog
  primitives.
- Group navigation into Home, Counter, Production, Delivery, Finance, Customers
  and Management, with role-specific landing workspaces.
- Add command palette, global cross-domain search, keyboard-first booking and
  clear mode/status indicators.
- Audit focus, labels, contrast, reduced motion, overflow and 1024/1366/4K/touch
  counter layouts using real operator scenarios.

No competitor visuals or private assets are used. New capability visuals remain
original Epic/Lndry assets, resized to runtime-appropriate derivatives.
