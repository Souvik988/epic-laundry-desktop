## Phase-1 completion definition

No production workspace receives generated operational records; demo data can only
exist in a deliberately selected isolated demo database; mode is visible; resetting
demo cannot touch production; first-run owner/business setup resumes safely after a
restart. Those facts require automated tests before Phase 1 is closed.
