# Vendor domain model

Planned normalized concepts: `platform`, `vendor`, `vendor_store`, `vendor_device`, `vendor_user`, `vendor_document`, `vendor_tax_profile`, `vendor_service_zone`, `vendor_capability`, `vendor_availability`, and `vendor_settlement_profile`.

Bank details and government documents must be references to tokenized/secure provider storage, never plaintext operational records. Vendor/store scope is a mandatory query predicate and must be tested against cross-vendor access.
