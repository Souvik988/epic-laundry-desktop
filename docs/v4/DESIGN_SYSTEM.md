# Design system V4

Current UI uses teal/cream operational screens alongside purple legacy/master screens and raw page-level colours. This is **PARTIAL**, not a unified design system.

V4 work will establish semantic colour and typography tokens, an offline-bundled licensed numeric-friendly UI font, and shared table/form/status/error/empty/detail primitives. The immediate visual defect fixed in this branch removes name-derived garment art and the fallback shirt; it does not claim a completed visual-system redesign.
