# Design system V4

Current UI uses teal/cream operational screens alongside purple legacy/master screens and raw page-level colours. This remains **PARTIAL**, not a fully unified application-wide design system. The V4 Online Orders cockpit now establishes a deliberate operator pattern: cream canvas, deep teal work-card surface, restrained amber/violet status accents, compact KPI strip, filter pills, queue list, and contextual detail panel.

V4 work will continue establishing semantic colour and typography tokens, an offline-bundled licensed numeric-friendly UI font, and shared table/form/status/error/empty/detail primitives. Runtime QA for the Online Orders surface passed at 1024, 1366, 1440, and 1920px with no horizontal overflow. The immediate visual defect fixed in this branch removes name-derived garment art and the fallback shirt; this document does not claim a completed visual-system redesign.
